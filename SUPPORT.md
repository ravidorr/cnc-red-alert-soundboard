# Support

- Bugs and feature requests: open a GitHub issue using the templates.
- Questions: open a GitHub issue with enough detail to reproduce the question.
- Security issues: see [SECURITY.md](./SECURITY.md).

## Troubleshooting

- Wrong Node version: run `nvm install && nvm use`.
- Hooks fail: run `npm run lint` and fix the reported errors. Do not bypass hooks.
- PWA assets look outdated: use the browser's site-storage controls to clear
  the cached site data, then reload.
